Android에서 WireGuard VPN 설정하는 방법

2025년 11월 25일

1. 새 구성 추가#

우측 하단의 + 버튼을 클릭합니다. (새 터널 추가 버튼)

이후 하단에 표시되는 직접 만들기(또는 Create from scratch)를 선택합니다.

2. 인터페이스 정보 입력#

  • 이름 : 단순 식별용도로만 사용되므로 임의로 지정하면 됩니다.
    • 예) wg0
  • 개인 키(Private Key) : 우측의 회전 아이콘 버튼을 누르면 개인 키와 공개 키가 자동 생성됩니다.
  • 공개 키(Public Key) : 자동 생성된 공개 키를 복사하여 서버 측 Peer 설정에 추가해야 합니다
    • 서버에 Peer 추가하는 방법은 (별도 포스팅으로 링크 연결 예정)
  • 주소(Address) : VPN 연결 시 사용할 사설 IP를 입력합니다.
    • 예) 10.0.0.2/24
  • DNS : VPN 사용 시 기본적으로 사용할 DNS 서버를 입력합니다.
    • 예) 서버 내부 DNS 또는 1.1.1.1 등

인터페이스 정보를 모두 입력한 뒤 피어 추가(Add Peer) 버튼을 클릭합니다.

3. 피어(Peer) 정보 입력#

  • 공개 키(Public Key) : VPN 서버 측의 공개 키를 입력합니다.
  • Persistent keepalive : WireGuard는 기본적으로 UDP 기반이기 때문에 NAT 환경에서 끊김이 발생할 수 있습니다. Keepalive 값(예: 25초)을 설정하면 연결 유지에 도움이 됩니다.
  • 엔드포인트(Endpoint) : 서버의 Public IP + WireGuard 포트를 입력합니다.
    • 예) 192.168.0.1:51820
  • 허용된 IP(Allowed IPs) : VPN 연결 시 어떤 트래픽을 VPN으로 보낼지 지정합니다.
    • 0.0.0.0/0 → 전체 트래픽을 VPN을 통해 라우팅
    • 특정 대역만 연결하고 싶다면 예: 10.0.0.0/24

피어 설정을 마치면 상단의 디스켓 아이콘(저장 버튼) 을 눌러 구성을 저장합니다.

4. VPN 연결 활성화#

저장 후 목록으로 이동하면 방금 생성한 터널이 표시됩니다. 해당 터널 오른쪽의 토글 스위치를 활성화하면 VPN 연결이 시작됩니다.
